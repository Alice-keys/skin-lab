# Skin Lab

## Summary
Skincare e-commerce application featuring a customer-facing storefront and an administrator dashboard, illustrating UI Components with Material Design, and API services integration, developed using Vue Framework, Axios, and PrimeVue.

## Features
- Browsing and searching skincare products by category
- Filtering and sorting products by price, popularity, and newest
- Managing a shopping cart with discount code support
- Managing a wishlist of favorite products
- Completing the checkout process and tracking orders
- Customer account registration, login, and profile management
- Administrator dashboard for product and category management
- Email subscription pop-up with welcome discount
- Internationalization (i18n)
- Mobile responsive design
- Environment variables
